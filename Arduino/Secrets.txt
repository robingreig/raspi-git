
Method 2: Global Header File (Shared Across Sketches)
If you have many projects using the same Wi-Fi, 
you can create a "secret library" to avoid repeating the file in every folder. 

Setup: Go to your libraries folder (find the path in File > Preferences) 
 and create a new folder named MySecrets.

Create File: Inside that folder, create a file named MySecrets.h with your #define statements.

Include: In any sketch, use #include <MySecrets.h> (note the angle brackets < > for libraries). 

I made a folder called /home/robin/raspi-git/Arduino/libraries/Secrets
And a file called Secrets.h containing:

#define SECRET_SSID_02 "Calalta02"
#define SECRET_PASS_02 "Micr0s0ft2018"

#define SECRET_SSID_03 ""Calalta03"
#define SECRET_PASS_03 "Micr0$0ft2024"

#define SECRET_SSID_T "Telus2547"
#define SECRET_PASS_T "g2299sjk6p"

And then can change this line in the reconnectWiFi function:
 Serialprintln("Connected to "SECRETS_SSID_02);
